# Portfolio
## Stack
- Next.js
- React
- Prisma
- Postgres
- Figma
- Framer
- Spline — no-code 3D editor, export scenes to web
- Rive — interactive vector animations and icons
- Lenis + GSAP ScrollTrigger — smooth scrolling + scroll-driven effects
- Locomotive Scroll — parallax + smooth scrolling out of the box
- ScrollReveal — easy “fade/slide in on scroll” animations
- Particles.js / tsparticles — interactive particle backgrounds
- Curtains.js — WebGL image/video distortion effects
- FullPage.js — full-screen scroll snapping between sections
- Swiper.js — touch-friendly sliders & carousels
- React Spring — physics-based animations (spring/bounce)
